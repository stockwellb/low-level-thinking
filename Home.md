# Low-Level Thinking

Short articles about low-level programming concepts, viewed through C. Each one explains the reasoning underneath a rule so you can derive the rule rather than memorize it.

Many explanations of C stop at what a feature does. These go one level down, to why it works the way it does. Some of the ideas here are rarely given a name. Others, such as how `const` binds in a declaration, are well defined but usually taught as rules to memorize rather than consequences to understand.

C is the lens, not the subject. Code appears only to make an idea concrete.
